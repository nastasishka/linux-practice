# Git Lab 6

Учебный проект для практической работы по Git.

## Цель проекта
Изучение основных команд Git, создание локального репозитория,
работа с коммитами и подключение к GitHub.

## Выполненные задачи
- Создан локальный Git-репозиторий.
- Выполнен первый коммит.
- Изменения подготовлены для отправки на GitHub.
